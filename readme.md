# Python Course Assignment 4: Functions and Loops

Welcome to this assignment in our Python course! Get ready to embark on an exciting journey as we dive into the powerful concepts of **functions** and **loops**.

Functions help you organize your code and make it reusable. Loops save you from rewriting many lines of code, allowing you to automate repetitive tasks and make your programs more efficient. Imagine executing a block of code multiple times without having to write it repeatedly—that's precisely what loops enable you to do!

In this assignment, you'll explore two types of loops in Python: the **`while` loop** and the **`for` loop**. Additionally, you'll learn about **loop control statements** such as `break` and `continue`, which allow you to alter the behavior of your loops based on specific conditions.

You'll encounter real-world examples that will challenge your problem-solving skills as you progress. By the end of this assignment, you'll have a solid foundation in using loops to automate repetitive tasks and solve complex problems.

So, buckle up and get ready to unleash the power of loops in Python! Join us in class this week, and let's level up your coding skills and unlock endless possibilities.

By the end of this lesson, you should be able to:

---

## Lesson Guidelines

- **`while` loop**: Learn how to create a loop that repeats as long as a certain condition is true. This is perfect for scenarios where you need to iterate until a specific condition is met.
- **`for` loop**: Ideal for situations where you already know or can programmatically determine how many times you want to repeat an action. Whether iterating over a sequence of elements or performing a set number of iterations, the `for` loop has got you covered.
